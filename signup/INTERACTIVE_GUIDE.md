# 대화형 회원가입 시스템 - 사용자 가이드

## 🎯 개요

사용자가 UI에서 직접 **네트워크를 선택**하고, 문제 발생 시 **관리자 승인 방식으로 전환**할 수 있는 대화형 시스템입니다.

## 📋 회원가입 흐름

### 기본 흐름 (즉시 검증)

```
1. 네트워크 선택 (TRC20 or BSC)
   ↓
2. 지갑 주소 확인 및 입금
   ↓
3. TXID 입력
   ↓
4. 자동 검증 (5-20초)
   ↓
5. ✅ 즉시 가입 완료!
```

### 대체 흐름 (관리자 승인)

```
1. 네트워크 선택 (TRC20 or BSC)
   ↓
2. "관리자 승인 방식으로 진행하기" 클릭
   ↓
3. 지갑 주소 확인 및 입금
   ↓
4. TXID 입력
   ↓
5. 📝 가입신청 완료 (승인 대기)
   ↓
6. ⏱️ 24시간 이내 관리자 승인
```

## 🎨 UI 구성

### 1단계: 네트워크 선택

사용자에게 두 가지 선택지가 제공됩니다:

```
┌─────────────┬─────────────┐
│  🌐 TRC20   │  ⚡ BSC     │
│  TRON       │  BNB Smart  │
│  낮은 수수료  │  빠른 처리   │
└─────────────┴─────────────┘

  검증에 문제가 있나요?
  관리자 승인 방식으로 진행하기 →
```

### 2단계: 지갑 주소 표시

선택한 네트워크에 맞는 지갑 주소가 표시됩니다:

```
TRC20 (TRON Network) 입금 주소
┌───────────────────────────────────┐
│ TAbcdefg1234567890...             │ 📋 복사
└───────────────────────────────────┘
```

### 3단계: TXID 입력

```
3. 입금 후 TXID를 입력하세요

┌───────────────────────────────────┐
│ 트랜잭션 ID (TXID)                 │
└───────────────────────────────────┘

⚡ 즉시 검증
TXID 입력 시 블록체인에서 자동으로
검증되어 즉시 가입이 완료됩니다.
```

## 🔄 검증 방식 전환

### TRC20 즉시 검증 → 관리자 승인

**시나리오:** TRC20 즉시 검증 실패 시

1. 사용자가 TRC20 선택
2. TXID 입력 후 제출
3. 검증 실패 (예: 금액 불일치, 네트워크 오류 등)
4. **자동으로 팝업 표시:**
   ```
   즉시 검증 실패: [에러 메시지]

   관리자 승인 방식으로 진행하시겠습니까?

   [예]  [아니오]
   ```
5. "예" 선택 시 → 관리자 승인으로 전환하여 제출
6. "아니오" 선택 시 → 다시 TXID 수정 가능

### 처음부터 관리자 승인 선택

**시나리오:** 즉시 검증을 원하지 않는 경우

1. 네트워크 선택 (TRC20 or BSC)
2. **"관리자 승인 방식으로 진행하기"** 클릭
3. UI가 관리자 승인 모드로 변경:
   - 네트워크 버튼이 살짝 투명해짐
   - 안내 메시지가 "관리자 승인 모드"로 변경
   - TXID 힌트가 "24시간 이내 승인"으로 변경
4. TXID 입력 후 제출
5. 가입신청 완료 (승인 대기)

## 🎯 사용자 경험 시나리오

### 시나리오 1: TRC20 즉시 검증 성공

**김철수 씨의 가입 과정**

1. **09:00** - 회원가입 페이지 접속
2. **09:01** - TRC20 선택 (낮은 수수료 선호)
3. **09:02** - 지갑 주소 복사하여 $100 USDT 입금
4. **09:05** - 입금 완료, TXID 복사
5. **09:06** - 회원가입 폼 작성 및 TXID 입력

7. **09:06** - 💫 자동 검증 중... (10초)
8. **09:06** - ✅ **즉시 가입 완료!** 회원코드 발급
9. **09:07** - 로그인 페이지로 이동

**소요 시간: 약 7분**

**박영희 씨의 가입 과정**

5. **14:11** - 💫 자동 검증 시도...

9. **14:11** - ✅ 가입신청 완료 (승인 대기)

6. **18:11** - ✅ 가입신청 완료 (관리자 확인 중)
7. **다음날 09:00** - 관리자 승인 완료
8. **다음날 09:05** - 이메일 수신 및 로그인

**안전하게 관리자 승인으로 진행**

## 💡 사용자를 위한 팁

### TIP 1: 어떤 네트워크를 선택해야 할까?

| 상황 | 추천 네트워크 |
|------|-------------|
| 수수료를 아끼고 싶다 | 🌐 **TRC20** (매우 저렴) |
| Binance를 주로 사용한다 | ⚡ **BSC** (빠르고 편리) |
| 빠른 확인을 원한다 | ⚡ **BSC** (확인 시간 짧음) |
| TRON 지갑이 있다 | 🌐 **TRC20** |

### TIP 2: 즉시 검증 vs 관리자 승인

**즉시 검증을 선택하세요:**
- ✅ 빠른 가입을 원할 때
- ✅ 입금 금액과 네트워크가 정확할 때
- ✅ 기술적으로 자신 있을 때

**관리자 승인을 선택하세요:**
- ✅ 안전하게 진행하고 싶을 때
- ✅ 자동 검증이 불안할 때
- ✅ 시간 여유가 있을 때 (24시간 이내)

### TIP 3: 검증 실패 시 대처법

즉시 검증이 실패하면:

1. **팝업이 뜹니다:** "관리자 승인 방식으로 진행하시겠습니까?"
2. **"예"를 선택하세요** → 안전하게 관리자 승인으로 전환
3. **"아니오"를 선택하면** → TXID를 다시 확인하고 재시도 가능

### TIP 4: 네트워크 주의사항

⚠️ **중요!**
- TRC20 선택 시 → **반드시 TRC20으로만 입금**
- BSC 선택 시 → **반드시 BSC로만 입금**
- 잘못된 네트워크로 입금하면 **복구 불가능!**
