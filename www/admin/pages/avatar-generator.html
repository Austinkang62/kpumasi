📋 아바타 자동 생성 시스템

작동 방식: Avatar Points가 $100 이상 적립된 회원의 아바타를 자동으로 생성합니다.

배치 처리: 매 5분마다 Cron Job이 자동 실행되어 대기 중인 모든 아바타를 생성합니다.

장점: Lock 충돌 없이 안정적으로 작동하며, 실패 시 수동 복구 가능합니다.

📐 아바타 생성 규칙

생성 조건

  • Avatar Points가 $100 이상 적립된 회원
  • $100당 아바타 1개 생성 (예: $250 → 2개 생성, $50 잔액)
  • is_avatar = 0 (일반 회원만, 아바타 제외)
  • deleted_at IS NULL (삭제되지 않은 회원만)

Avatar Points 적립 방식

  • 모든 보너스의 35%가 Avatar Points로 적립
  • 나머지 65%는 현금(캐시)으로 지급
  • 보너스 종류: Referral(추천), Edge(엣지), Matching(매칭), Rollup(롤업)
  • 4가지 보너스 모두 65%/35% 분리 적용

생성 프로세스

  • 아바타 계정 생성 (user_id: AVA00001, AVA00002, ...)
  • Binary Tree 스필오버 위치 배치 (BFS 알고리즘)
  • 부모 회원의 Avatar Points $100 차감
  • 아바타에 $100 매출 자동 기록
  • 4가지 보너스 자동 계산 및 지급
  • 트랜잭션으로 안전하게 처리 (실패 시 자동 롤백)
