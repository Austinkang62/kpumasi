프로젝트 개요

Binary Tree 기반 MLM(Multi-Level Marketing) 시스템의 완벽한 템플릿입니다.
조직도, 구매, 출금, 보너스, 아바타 시스템이 모두 구현되어 있습니다.

🌳

Binary Tree System

이진 트리 구조로 조직을 관리하며, BFS 알고리즘으로 자동 배치됩니다.

  • BFS 자동 배치 알고리즘
  • 15단계 레그 시스템
  • 실시간 조직도 시각화
  • 매출 상태별 컬러 표시
📦

Package System

$50과 $100 두 가지 패키지를 제공하며, 자동 업그레이드가 지원됩니다.

  • $50 기본 패키지
  • $100 프리미엄 패키지
  • 자동 업그레이드 ($50+$50)
  • USDT TRC20 결제
💰

15-Level Bonus

직접 추천 수에 따라 최대 15단계까지 보너스를 받을 수 있습니다.

  • 1명 추천 → 5단계 보너스
  • 2명 추천 → 10단계 보너스
  • 3명+ 추천 → 15단계 보너스
  • 패키지별 차등 지급
💵

Withdrawal System

주 1회 출금이 가능하며, 아바타 구간 제한이 적용됩니다.

  • 주 1회 출금 제한
  • 최소 $10 출금
  • 아바타 구간 출금 제한
  • USDT BNB Smart Chain
🤖

Avatar System

보너스 포인트로 아바타를 구매하여 조직을 자동 확장합니다.

  • $150/$300 배수마다 트리거
  • $50 회원: 1개씩
  • $100 회원: 2개씩
  • BFS 자동 배치

빠른 시작

3단계로 간단하게 시작할 수 있습니다. 

# 1. 템플릿 복사
cp -r template_nrp your_project_name
cd your_project_name

# 2. 데이터베이스 생성
mysql -u root -p
CREATE DATABASE your_db_name CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE your_db_name;
SOURCE database/schema.sql;

# 3. 설정 파일 수정
nano config/database.php
# DB 정보 입력 (호스트, 사용자명, 비밀번호, DB명)
# database.php 설정 예시
define('DB_HOST', 'localhost');
define('DB_NAME', 'your_db_name');
define('DB_USER', 'your_db_user');
define('DB_PASS', 'your_password');

# USDT 입금 주소 설정 (purchase.html)
value="YOUR_USDT_TRC20_ADDRESS"

# 관리자 계정 생성
INSERT INTO users (user_id, password, email, role)
VALUES ('admin', PASSWORD_HASH, 'admin@example.com', 'admin');
# Apache 설정
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /var/www/your_project_name
    <Directory /var/www/your_project_name>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>

# 파일 권한 설정
chown -R www-data:www-data /var/www/your_project_name
chmod -R 755 /var/www/your_project_name

# Apache 재시작
systemctl restart apache2
