📋 시스템 개요

🌳 이진 트리 구조
모든 회원은 이진 트리 형태로 조직됩니다. 각 회원은 최대 2명의 직접 하위 회원을 가질 수 있으며, BFS(너비 우선 탐색) 알고리즘으로 자동 배치됩니다.
💎 패키지 기반
$50 패키지와 $100 패키지 두 가지가 있습니다. $50 회원이 $50을 추가 구매하면 자동으로 $100 회원으로 업그레이드됩니다.
🎯 15단계 보너스
하위 회원의 패키지 구매 시 최대 15단계까지 보너스를 받을 수 있습니다. 단, 직접 추천인 수에 따라 깊이가 결정됩니다.

👥 회원 추천 시스템

핵심 원리: 추천인 코드로 가입하면 이진 트리 구조로 자동 배치되며, 직접 추천한 회원 수에 따라 보너스를 받을 수 있는 깊이가 결정됩니다.
직접 추천인 수 보너스 지급 깊이 설명
1명 5단계 하위 5단계까지의 구매에 대해 보너스 지급
2명 10단계 하위 10단계까지의 구매에 대해 보너스 지급
3명 이상 15단계 하위 15단계까지의 구매에 대해 보너스 지급
나 (3명 직접 추천 = 15단계)

🌳 조직도 표시 규칙

📍 기본 원칙:
조직도는 로그인한 사용자를 최상단 루트로 하여 하위 조직을 표시합니다.
직접 추천인 수에 따라 조직도에 표시되는 깊이가 제한됩니다.
직접 추천인 수 조직도 표시 깊이 보너스 지급 깊이 비고
1명 5단계까지 5단계까지 표시 범위와 보너스 범위 동일
2명 10단계까지 10단계까지 표시 범위와 보너스 범위 동일
3명 이상 15단계까지 15단계까지 전체 조직도 표시 + 전체 보너스

모든 회원:
• 조직도 표시 범위 = 보너스 지급 범위
• 조직도에 보이는 회원의 구매만 보너스 발생 ✅

예시:
A회원(1명 추천)의 하위 5단계에서 B회원이 $100 패키지를 구매하면,
• 조직도에 B회원이 표시됨 ✅
• A회원은 $4.5 보너스를 받습니다!
💡 조직 확장 전략:

초기 단계 (1명 추천):
조직도 5단계 표시, 보너스 5단계 지급으로 기본 수익 구조 확보

성장 단계 (2명 추천):
10단계까지 조직을 눈으로 확인하며 관리 가능, 보너스도 10단계까지 확대

완성 단계 (3명 이상 추천):
전체 15단계 조직도를 확인하며 최대 수익 구조 달성 🎉

🤖 아바타 수동 구매 시스템

아바타란? 보너스 포인트로 구매하는 $50짜리 추가 패키지입니다. 아바타도 조직도에 배치되어 보너스를 발생시키지만, 아바타 구매 자체는 상위 라인에게 보너스를 발생시키지 않습니다.
💡 수동 구매 프로세스:
1. 보너스 $150/$300 달성 시 대시보드에 알림 표시
2. 아바타 구매 페이지로 이동
3. 보너스 포인트로 결제 (1 포인트 = $1 USDT)
4. 아바타 생성 및 조직도 자동 배치
