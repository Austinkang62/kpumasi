💎 보너스 규칙 상세 안내

K-Pumasi의 4가지 보너스 시스템에 대한 완벽한 가이드
각 보너스의 계산 방법, 지급 조건, 실제 예시를 확인하세요

👥

1. 추천 보너스 (Referral Bonus)

직접 추천한 회원으로부터 받는 보너스

📋 기본 개념

추천 보너스는 회원님이 직접 추천(소개)한 회원이 패키지를 구매할 때 지급되는 보너스입니다. 추천인-피추천인 관계에서 발생하는 가장 기본적인 보너스로, 네트워크 확장의 핵심 동력입니다.

보너스 비율: 25%
직접 추천한 회원의 패키지 금액 중 25%를 보너스로 지급받습니다.

💰 계산 방식

추천 보너스 = 피추천인 패키지 금액 × 25%
📌 예시

상황: A회원이 B회원을 추천하여 가입시킴
조건: B회원이 $100 패키지 구매
계산: $100 × 25% = $25
결과: A회원은 $25 추천 보너스를 받음

💡 지급 조건
  • 피추천인이 회원가입 시 추천인 코드를 정확히 입력해야 함
  • 피추천인의 패키지 구매가 완료되어야 보너스 지급
  • 즉시 지급되며, 출금 가능한 잔액에 추가됨
⚡

2. 엣지 보너스 (Edge Bonus)

바이너리 트리 구조에서 발생하는 전환점 보너스

📋 기본 개념

엣지 보너스는 바이너리 트리(Binary Tree) 조직도에서 새로운 회원이 좌측 또는 우측에 배치될 때, 그 위치의 상위 라인 회원들에게 지급되는 보너스입니다. "엣지(Edge)"는 트리 구조에서 노드 간의 연결선을 의미하며, 새로운 연결이 생성될 때마다 발생합니다.

보너스 비율: 25%
새로운 회원의 패키지 금액 중 25%를 엣지 보너스로 지급합니다.

🌳 바이너리 트리 구조

A (후원인) / \ 좌측 (B) 우측 (C) / \ / \ D E F G

각 회원은 최대 2명(좌측 1명, 우측 1명)의 직접 하위를 가질 수 있습니다.
새로운 회원이 배치될 때마다 상위 라인에 엣지 보너스가 발생합니다.

💰 계산 방식

엣지 보너스 = 신규 회원 패키지 금액 × 25%

신규 회원이 특정 위치(좌측 또는 우측)에 배치될 때,
그 위치의 직계 상위 라인 회원에게 지급됩니다.

📌 예시

상황: A회원의 좌측 하위에 D회원 배치
조건: D회원이 $100 패키지 구매
계산: $100 × 25% = $25
결과: A회원은 $25 엣지 보너스를 받음

💡 지급 조건
  • 신규 회원이 바이너리 트리에 배치되어야 함 (후원인 지정)
  • 신규 회원의 패키지 구매가 완료되어야 함
  • 상위 라인 회원 중 해당 위치의 직계 상위에게만 지급
  • 좌측/우측 각각 별도로 계산됨
🤝

3. 추천매칭 보너스 (Matching Bonus)

엣지 보너스에 연동되는 추가 보너스

📋 기본 개념

추천매칭 보너스는 회원님이 직접 추천한 회원(추천인 라인)이 엣지 보너스를 받을 때, 그에 연동하여 회원님에게도 추가로 지급되는 보너스입니다. 추천인 관계와 후원인 관계가 결합하여 발생하는 특별 보너스입니다.

보너스 비율: 25%
직접 추천한 회원이 받는 엣지 보너스의 25%를 추가로 지급받습니다.

🔗 발생 조건

  • 회원 A가 회원 B를 추천으로 가입시킴
  • 회원 B가 자신의 하위에 회원 C를 후원으로 배치
  • 회원 C가 패키지 구매 → 회원 B는 엣지 보너스 수령
  • 이때 회원 A는 추천매칭 보너스 수령

💰 계산 방식

추천매칭 보너스 = 직접 추천인의 엣지 보너스 × 25%
📌 예시

관계:
- A회원이 B회원을 추천
- B회원이 C회원을 후원 (좌측 배치)
- C회원이 $100 패키지 구매

1단계: B회원의 엣지 보너스
$100 × 25% = $25 (엣지 보너스)

2단계: A회원의 추천매칭 보너스
$25 × 25% = $6.25 (추천매칭 보너스)

💡 핵심 포인트
  • 추천인 관계가 있어야만 발생 (후원인만으로는 불가)
  • 직접 추천인이 엣지 보너스를 받을 때만 발생
  • 2단계 깊이까지만 적용 (추천인의 추천인까지)
  • 추천인의 조직 성장을 지원하는 인센티브
📊

4. 롤업 보너스 (Rollup Bonus)

후원 계보 25단계 깊이까지 1%씩 지급

📋 기본 개념

롤업 보너스는 후원인 계보를 따라 상위 25단계까지의 모든 회원에게 지급되는 보너스입니다. "Rollup"은 하위의 실적이 상위로 "말려 올라가는" 개념으로, 조직의 깊이와 규모에 따라 장기적으로 누적되는 수익입니다.

보너스 비율: 각 단계당 1%
신규 회원 패키지 금액의 1%를 상위 25단계 각각에게 지급합니다.

📊 후원 계보 구조

레벨 0: 회원 Z (신규 가입, $100 구매) ↑ 후원 레벨 1: 회원 Y → $1 (1%) ↑ 후원 레벨 2: 회원 X → $1 (1%) ↑ 후원 레벨 3: 회원 W → $1 (1%) ... 레벨 25: 회원 A → $1 (1%)

💰 계산 방식

각 단계 롤업 보너스 = 신규 회원 패키지 금액 × 1%

신규 회원 1명 가입 시, 상위 25명에게 각각 1%씩 지급됩니다.

📌 예시

상황: Z회원이 $100 패키지로 가입
후원 계보: A ← B ← C ← ... ← Y ← Z

보너스 지급:
- Y회원 (1단계): $100 × 1% = $1
- X회원 (2단계): $100 × 1% = $1
- W회원 (3단계): $100 × 1% = $1
- ...
- A회원 (25단계): $100 × 1% = $1

총 지급액: $25 (25명 × $1)

💡 핵심 포인트
  • 후원인 계보를 따라서만 지급 (추천인 계보와 무관)
  • 최대 25단계까지만 지급
  • 모든 신규 가입자마다 발생하므로 누적 효과가 큼
  • 조직이 깊어질수록 자동으로 증가하는 장기 수익
  • 각 단계는 동일하게 1%씩 받음 (차등 없음)
💎 장기 수익 시뮬레이션
만약 회원님의 하위 25단계에 각 단계마다 평균 2명씩 있다면:
- 1단계: 2명
- 2단계: 4명
- 3단계: 8명
- ...
- 25단계: 33,554,432명

각 회원이 $100 패키지로 가입할 때마다 회원님은 $1의 롤업 보너스를 받게 됩니다!

👥 추천 보너스 25% 직접 추천한 회원 가입 $25
⚡ 엣지 보너스 25% 바이너리 트리 배치 $25
🤝 추천매칭 보너스 25%×25% 추천인의 엣지 보너스 $6.25
