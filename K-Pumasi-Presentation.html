프로젝트 개요

K-Pumasi는 혁신적인 네트워크 마케팅 플랫폼입니다

💡

• 공정성: 모든 회원에게 동등한 기회

조직도 시스템

추천기준 바이너리 트리 (Binary Tree)

[후원자] | [회원A] / \ [왼쪽] [오른쪽] (Left) (Right) / \ / \ [B] [C] [D] [E]
🌳
구조 특징
• 각 회원은 최대 2명의 직속 하위 회원 추천 가능
• 왼쪽 레그(Left Leg), 오른쪽 레그(Right Leg) 구조
• sponsor_position: 1=좌측, 2=우측
📊
조직 관리
• 실시간 조직도 시각화
• 좌/우 레그별 매출 현황 확인
• 하위 멤버 수 자동 카운팅
• 레벨별 깊이 추적

추천인 vs 후원인

두 가지 관계의 차이점

👥
추천인 (Referral)
referral_id

• 직접 추천한 사람
• 추천 보너스 발생
• 매칭 보너스 대상
• 1:N 관계 가능

예시: A가 B, C, D를 모두 추천 가능
🌳
후원인 (Sponsor)
sponsor_id + sponsor_position

• 바이너리 트리 상 부모
• 엣지 보너스 발생
• 롤업 보너스 계보
• 좌측/우측 위치 지정

예시: A의 좌측에 B, 우측에 C 배치
💡 핵심 개념
추천인과 후원인은 다를 수 있습니다!
예: A가 B를 추천했지만, B는 C의 후원인 하위에 배치될 수 있음
→ 이 경우 A는 추천 보너스를 받고, C는 엣지 보너스를 받습니다.

2. 엣지 보너스 (Edge Bonus)

방향이 바뀌는 지점에서 발생하는 보너스

[A] / \ [B] [C] / [D] ← (sponsor_position=1, 좌측) / [E] ← 신규 가입 ($100, sponsor_position=1, 좌측) E 가입 시: - E의 position = 1 (좌측) - D의 position = 1 (좌측) → 방향 동일, 계속 상위로 - B의 position = 1 (좌측) → 방향 동일, 계속 상위로 - A 도달 → B가 A의 좌측에 배치됨 → A가 엣지 보너스 $25 수령
항목 설명
지급 대상 상위로 올라가면서 sponsor_position이 바뀌는 첫 지점의 부모
계산 방식 신규 회원 패키지 금액 × 25%
로직 1. 신규 회원 position부터 시작
2. 상위로 올라가며 position 비교
3. 처음 바뀌는 지점의 부모에게 지급
구현 위치 classes/BonusDistributor.php:170-276
